### What this means for this project — plain English

**✅ Using the art on this website is allowed.** This is a project website,
the art is part of it, and the licence explicitly permits both personal and
commercial use. Nothing about the way the cat is built breaks these terms.

**❌ What is not allowed** is handing the art out *as art* — uploading the pack
somewhere for others to download, selling it, or including it in something
whose purpose is to distribute assets. That is what "redistributing these
materials separately" means.

### ⚠️ One thing worth a moment's thought

This site is hosted on GitHub Pages from a **public repository**. That means
the PNG files sit at public web addresses and anyone can download them
directly.

My honest read: **this is fine and is normal permitted use.** Any website that
shows an image has to send that image to the visitor's browser — there is no
way to display art without serving it. Serving the art *as part of your
website* is using it in a project, not redistributing it as an asset pack.

But two cheap habits remove any ambiguity, and both are worth doing:

1. **Only commit the files the site actually uses.** Put the four cat colours
   in `sprites/` and the items you sell in `items/` — and nothing else. Do
   **not** upload the pack's original `.zip`, its own README or licence file,
   promotional images, or the nine cat colours the site never shows. A folder
   containing the whole pack looks like a copy of the pack. A folder
   containing exactly what the site displays looks like a website.
2. **Credit the artist** (see below). Not required by the wording above, but
   it costs nothing, it is good practice for a public-health project from a
   university, and it makes your intent obvious to anyone who wonders.

If you would rather be extra careful, the alternative is keeping the
repository private and publishing only the built site — but GitHub Pages on a
private repository needs a paid plan, and I do not think the situation calls
for it.
